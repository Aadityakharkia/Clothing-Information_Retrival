HOW IT WORKS

The positional intersection algorithm merges the postings lists of two terms using two pointers p₁ and p₂. For each common document ID, it checks if any position pair satisfies 0 < pos(t₂) − pos(t₁) ≤ k. This guarantees exact positional evidence — not just co-occurrence — proving the postings index is used.
